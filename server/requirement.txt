# ------------------------------------------------------------------------------
# 5. HOW TO RUN THE PROJECT
# ------------------------------------------------------------------------------
# 1. Database Setup: Run TABLES.sql and Queries.sql in SQL Server Management Studio
# 2. Start Backend:  cd server && npm install && npm run dev
# 3. Start Frontend: cd client && npm install && npm run dev
# 4. Stripe Webhook: stripe listen --forward-to localhost:5000/api/orders/webhook
